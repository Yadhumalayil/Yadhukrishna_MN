# Yadhukrishna M N — Portfolio Website

This folder contains the GitHub Pages-ready version of the portfolio website.

## Files

- `index.html` — complete responsive portfolio website. The supplied HTML includes its video and image media as embedded data, so no separate media folder is required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository (for example, `yadhukrishna-portfolio`).
2. Upload `index.html` and `README.md` to the **top level** of the repository (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to finish deploying. Your site URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/yadhukrishna-portfolio/`

## Updating the website

Edit `index.html` and commit the changes to the repository. GitHub Pages will redeploy automatically.

## Notes

- The page uses Google Fonts when an internet connection is available; fallback system fonts are defined in the CSS.
- Keep `index.html` at the repository root. GitHub Pages uses it as the website homepage.
- Check all contact and social links in the live site before sharing it with employers.
